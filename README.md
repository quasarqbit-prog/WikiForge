# WikiForge

Легковесный, 100% офлайн-генератор вики-документации в один HTML-файл, разработанный для модульных проектов, игр и модификаций.

---

## О проекте

Изначально **WikiForge** создавался с упором на **создателей дата-паков и модов для Minecraft**. Документировать сложные кастомные механики, шейдеры или компоненты предметов бывает довольно изнурительно — особенно когда хочется, чтобы вся информация поставлялась вместе с самим проектом и не зависела от сторонних сайтов.

С помощью WikiForge вы можете быстро набросать всю необходимую документацию, гайды по крафту и описание механик в удобном Markdown-редакторе. Затем утилита компилирует всё это в **один-единственный легковесный файл `WIKI.html`** (размером примерно с обычную картинку).

Для авторов дата-паков это открывает идеальный сценарий: вы просто закидываете готовый `WIKI.html` прямо в папку своего дата-пака и добавляете в чат приветственное уведомление через `load.mcfunction`:
> *"Загляни в папку дата-пака, там есть файл `WIKI.html` — там вся инфа, крафты и гайд по механикам!"*

---

## Не только для Minecraft!

Хотя инструмент идеально вписывается в экосистему Майнкрафта, **WikiForge абсолютно универсален** и отлично подойдет в качестве инструмента документирования для:

*   **Моддинга других игр:** Идеально подходит для упаковки руководств внутрь zip-архивов с модами для таких игр, как *Terraria (tModLoader)*, *Project Zomboid*, *RimWorld* или *Factorio*.
*   **Инди-разработчиков:** Автономный и удобный способ вести свои **дизайн-документы (GDD)** или создавать офлайн-руководства к играм.
*   **Администраторов серверов:** Позволяет легко создавать красиво оформленные, высококонтрастные своды правил и FAQ для локальных игровых серверов.
*   **Общей IT-разработки:** Отличный "офлайн-фёрст" генератор статических сайтов для любых легковесных проектов, где не хочется связываться с внешним веб-хостингом или сложными вики-фреймворками.

---

## Ключевые фишки

*   **Offline-First:** Работает локально в любом браузере абсолютно без интернета. Ноль зависимостей.
*   **Архитектура одного файла:** Вся вики-структура, стили и контент живут ровно в *одном* файле `.html`. Его легко переносить, легко делиться.
*   **Поддержка Markdown:** Пишите документацию, используя привычный и чистый синтаксис Markdown.
*   **Минималистичный высококонтрастный дизайн:** Интерфейс спроектирован так, чтобы быть удобным для разработчиков, а текст легко читался с первого взгляда.

---

## Как использовать

1. Откройте редактор WikiForge.
2. Напишите вашу документацию или дизайн-заметки в Markdown.
3. Экспортируйте автономный файл `WIKI.html`.
4. Закиньте его в папку вашего проекта — и всё готово!

# WikiForge

A lightweight, 100% offline, single-file HTML wiki generator designed for modular projects, games, and documentation.

---

## About The Project

**WikiForge** was originally built with **Minecraft datapack and mod creators** in mind. Documenting complex custom mechanics, core shading, or item components can be a pain, especially when you want to keep everything contained. 

With WikiForge, you can write all your documentation, custom crafting recipes, and guides using a clean Markdown editor. It then compiles everything into a **single, lightweight `WIKI.html` file** (about the size of a regular image). 

For Minecraft creators, this means you can drop `WIKI.html` directly into your datapack or mod folder and send an in-game welcome notification via `load.mcfunction`:
> *"Check out the `WIKI.html` file inside the datapack folder for a complete guide and mechanics!"*

---

## Not Just for Minecraft!

While it fits the Minecraft ecosystem perfectly, **WikiForge is universally adaptive** and serves as an excellent documentation tool for:

*   **Game Modding:** Perfect for packaging guides inside zip archives for games like *Terraria (tModLoader)*, *Project Zomboid*, *RimWorld*, or *Factorio*.
*   **Indie Game Devs:** A standalone way to maintain your **Game Design Documents (GDD)** or offline game manuals.
*   **Server Administrators:** Easily create beautifully formatted, high-contrast rulesets and FAQ files for local game servers.
*   **General Software:** A perfect "offline-first" static site generator for any lightweight IT project where you don't want to deal with external web hosting or complex wiki frameworks.

---

## Key Features

*   **Offline-First:** Runs natively in any browser completely without internet. Zero dependencies.
*   **Single-File Architecture:** The entire wiki, layout, and content live inside exactly *one* `.html` file. Easy to share, easy to move.
*   **Markdown Support:** Write using comfortable, clean Markdown syntax.
*   **High-Contrast & Minimalist:** Designed with an aesthetic, scannable, and developer-friendly UI.

---

## How to Use

1. Open the WikiForge editor.
2. Write your documentation or design notes in Markdown.
3. Export your standalone `WIKI.html` file.
4. Drop it into your project folder, and you are good to go!
